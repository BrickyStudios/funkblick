Open a Funkblick log

See a shared drive on any phone, iPhone included.

The file stays in this browser, nothing is uploaded. Map tiles come from OpenFreeMap, which sees the area on screen. You can also drop files onto the page.

How to get a file: in Funkblick, open More and export the drive. JSON carries the device list and the alerts, GeoJSON the route and where devices were. Safe mode is on from the start: it shortens addresses and hides the names of homes and phones, so the JSON file can be passed on. The GeoJSON file holds your exact route, including where you started: share it only with people who may know that.
