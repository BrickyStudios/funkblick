Funkblick-Log ansehen

Eine geteilte Fahrt auf jedem Handy ansehen, auch auf dem iPhone.

Die Datei bleibt in diesem Browser, nichts wird hochgeladen. Die Kartenkacheln kommen von OpenFreeMap, das den angezeigten Ausschnitt sieht. Dateien lassen sich auch auf die Seite ziehen.

So kommst du an eine Datei: In Funkblick unter Mehr die Fahrt exportieren. JSON enthält die Geräteliste und die Warnungen, GeoJSON die Strecke und wo die Geräte standen. Der sichere Modus ist von Anfang an an und kürzt Adressen und blendet die Namen von Heimnetzen und Handys aus, so lässt sich die JSON-Datei weitergeben. Die GeoJSON-Datei enthält deine genaue Strecke samt Startpunkt: Teile sie nur mit Leuten, die das wissen dürfen.
